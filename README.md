# Ragdoll-Parkour
This is a simple game with procedural animations and parkour.

PC controls: WD — movement, W/Space — jump, S — crouch, Shift — sprint, CTRL — ragdoll.

Press jump while running near a box to quickly vault over it.

Open RagdollParkour.html for PC and other devices or install RagdollParkour.apk for Android.
